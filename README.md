# SillyTavern - IF Lorebook

See which WorldInfo / Lorebook entries were active in the last generated message — and why they were activated (matched keywords, recursion, constant, sticky, vectorized).

Click the book button to see the list of active entries. Drag the button to move it anywhere on screen. Right click for options.

Fork of [SillyTavern-WorldInfoInfo](https://github.com/LenAnderson/SillyTavern-WorldInfoInfo) by LenAnderson.
